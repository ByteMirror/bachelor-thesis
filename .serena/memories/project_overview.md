# Project Overview: Bachelor Thesis - Atlas VTT

## Purpose
A German Bachelor thesis (50 pages) about **Performance Optimization and Benchmarking of a VTT Plugin for Obsidian**.

**Research Question**: "Welche Herausforderungen ergeben sich bei der Umsetzung eines VTT-Plugins in Obsidian.md, und wie beeinflussen diese Performance, Wartbarkeit und Entwicklungsaufwand?"

## Tech Stack
- **Document**: LaTeX with BibLaTeX/Biber for citations
- **Subject**: PIXI.js v8, Electron, TypeScript (the VTT plugin being analyzed)
