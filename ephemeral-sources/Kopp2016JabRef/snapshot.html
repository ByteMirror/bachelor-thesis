About JabRef

JabRef is a free, open-source reference management tool designed for researchers and students. Founded in 2003, it helps users collect, organize & discover academic literature efficiently.

The project emphasizes its commitment to open access and operates using a simple text-based file format with no vendor lock-in.

Core Features

Collect

  • Import from 15+ reference formats
  • Retrieve full-text articles
  • Fetch complete bibliographic information based on ISBN, DOI, PubMed-ID and arXiv-ID
  • Browser extension integration

Edit

  • Compare data with online catalogues (Google Scholar, Springer, MathSciNet)
  • Auto-rename and move associated files
  • Customize metadata fields

Organize

  • Create hierarchical collections
  • Use advanced search/filtering
  • Track reading status with ranking and priority systems
  • Organize articles by keywords, tags, and custom assignments

Cite

  • Native BibTeX/BibLaTeX support
  • Cite-as-you-write functionality for external apps (Emacs, LyX, Texmaker, etc.)
  • Compatibility with Word/LibreOffice/OpenOffice
  • Thousands of built-in citation styles
  • Integration with LaTeX and Markdown

Browser Extensions

Available for Chrome, Firefox, Edge, and Vivaldi

Community & Development
